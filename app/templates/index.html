      Encryption Settings

      Database encryption is OFF. Private keys (CA keys, certificate keys, SSH private keys) are stored in plaintext in the SQLite database.

      What this protects: If someone copies your database file (~/.cert-generator/certs.db), they cannot read your private keys without the master password.

      What this does NOT protect: While the app is running and unlocked, keys are decrypted in memory. This protects data at rest, not a running application.

      Recovery key: When you enable encryption you'll get a one-time recovery key. It's the only way back in if you forget the password, so store it somewhere safe, away from this machine. It's shown once.

      Cloudflare CRL Workers

      Each CA can publish its CRL from its own Cloudflare Worker, so clients anywhere can check revocation without reaching this server. The app pushes a new CRL on every revocation and renews it weekly. Set it up once here, then deploy a Worker from a CA's page.

      Turn on database encryption first: the API token can rewrite your CRL Workers, so it is only ever stored encrypted.

      Connected to account .

      Workers this app created

      1. Create an API token

      1. Open dash.cloudflare.com › My Profile › API Tokens and choose Create Token › Create Custom Token.
      2. Permissions: Account · Workers Scripts · Edit. That is all a workers.dev address needs.
      3. For an address on your own domain, also add Zone · Zone · Read, Zone · Workers Routes · Edit and Zone · DNS · Edit, and under Zone Resources pick only that domain.
      4. Account Resources: only your account. Optionally limit it to this server's public IP under Client IP Address Filtering.
      5. Create it and copy the token. Cloudflare shows it once.

      2. Connect

      The token is checked with Cloudflare, then stored encrypted with your database key. It is never shown again, and the app can't use it while the database is locked.

      Deploy a CRL Worker

      Creates a Worker for that serves only its CRL, read-only. Choose the address certificates will carry.

      The address is written into every certificate you issue with it, so pick one you'll keep. Tearing the Worker down later leaves those certificates without a working CRL.
